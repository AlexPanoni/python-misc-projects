# Python Misc Projects

This repository is a collection of small Python practice projects and games.  
They are not related to my professional Data Analysis work — just fun utilities I built while learning Python.

## Projects included

### 🎮 Tic Tac Toe
A simple one-player Tic Tac Toe game to play against the computer that runs in the terminal.  
- **Folder:** `TicTacToe/`  
- **Run:**  
python TicTacToe.py


### ✊✋✌️ Jokenpo (Rock, Paper & Scissors)
Play Rock, Paper & Scissors against the computer.  
- **Folder:** `Jokenpo(RPS)/`  
- **Run:**  
python Jokenpo(RPS).py


### 🔢 Guess the Number
The computer picks a random number, and you try to guess it in as few attempts as possible.  
- **Folder:** `Guess_Number/`  
- **Run:**  
python Guess_Number.py


### 🚗 Car Rental System
A simple text-based system to simulate renting a car.  
- **Folder:** `AutoRent/`  
- **Run:**  
python AutoRent.py
